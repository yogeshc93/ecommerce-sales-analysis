## Project Overview
An Excel-based dashboard created to analyse e-commerce sales performance and identify business trends.

## Objectives
- Analyse total revenue and order volume.
- Calculate average order value.
- Compare product performance.
- Explore regional sales trends.

## Tools Used
- Microsoft Excel
- Formulas and PivotTables
- Charts and dashboard visualisation

## Key Metrics
- Total revenue
- Total orders
- Average order value
- Product and regional performance
